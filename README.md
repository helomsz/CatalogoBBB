# 📺 Catálogo BBB - React

Projeto desenvolvido com o objetivo de **revisar e praticar conceitos de React**, utilizando como tema um **catálogo do Big Brother Brasil (BBB)**.

A aplicação reúne participantes, momentos icônicos e um carrossel com todas as edições do programa, trazendo interatividade e funcionalidades comuns em aplicações reais.

---

## 🚀 Funcionalidades

- 📋 **Catálogo de participantes do BBB**
- ⭐ **Favoritar participantes**
- 🔢 **Contador de participantes favoritados**
- 🏷️ **Filtro de participantes por adjetivos relacionados ao BBB**
- 🎞️ **Carrossel com todas as edições do BBB**
- 📱 **Navbar responsiva**
- 💡 **Exibição de momentos icônicos do programa**

---

## 🛠️ Tecnologias Utilizadas

- **React**
- **JavaScript (ES6+)**
- **CSS**
- **HTML**
